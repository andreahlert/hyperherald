wire format spec

v0, 2026. Breaking changes allowed in 0.x.

_hyperherald frames are HTML custom elements with structured attributes. No JSON envelope. The browser parses them with DOMParser and applies them to the DOM via the runtime.

envelope

Every frame is an HTML custom element with three required attrs and N type-specific attrs.

attrtyperequiredmeaning
channelstringyestopic the client subscribed to.
sequint64yesmonotonic sequence per channel. Used as replay cursor.
vuint8no (default 0)protocol version. 0.x permits breaks.
tsiso8601noserver-side timestamp.

frame types

1. hh-fragment

Single targeted swap.

<hh-fragment channel="orders:42" seq="17"
             target="#status"
             swap="inner">
  shipped
</hh-fragment>

swap values: inner, outer, append, prepend, before, after, delete, replace.

2. hh-multi

Multiple fragments applied in order. Not atomic.

<hh-multi channel="chat:lobby" seq="42">
  <hh-fragment target="#count" swap="inner">3</hh-fragment>
  <hh-fragment target="#log"   swap="append"><li>hi</li></hh-fragment>
</hh-multi>

3. hh-atomic

Multiple fragments buffered then flushed in one mutation. Use for state that should never be inconsistent (price plus leader plus countdown).

<hh-atomic channel="auction:lot-1" seq="99">
  <hh-fragment target="#price"     swap="inner"><strong>$120</strong></hh-fragment>
  <hh-fragment target="#leader"    swap="inner">alice</hh-fragment>
  <hh-fragment target="#countdown" swap="inner">30</hh-fragment>
</hh-atomic>

4. hh-partial

Progressive append, terminates with final. Designed for LLM token streaming.

<hh-partial channel="chat:reply-99" seq="5"
            target="#answer"
            suspense_id="reply-99">
  the wire is HTML
</hh-partial>

5. hh-subscribe-ack

Server confirms subscription, optionally with replay cursor for missed frames.

<hh-subscribe-ack channel="orders:42"
                  cursor="17"></hh-subscribe-ack>
