patterns

Five common shapes for streaming hypermedia. Copy, adapt, ship.

1. live auction

Multi-tab consistent state. Atomic frames keep price, leader and countdown in sync.

<div _herald="/sse" _herald-subscribe="auction:lot-1">
  <span id="price">$100</span>
  <span id="leader">nobody</span>
  <span id="countdown">60</span>
</div>
<!-- server publishes hh-atomic with all three fragments -->

Live: auction.html

2. dashboard with backpressure

High-frequency metrics. Coalesce intermediate frames, only render last per key per window.

<div _herald="/ws"
     _herald-subscribe="metrics:cpu metrics:mem metrics:io"
     _herald-coalesce="key:target window:200ms strategy:last"
     _herald-buffer="max:50 drop:oldest">
  <span id="cpu">0%</span>
  <span id="mem">0 GB</span>
  <span id="io">0 MB/s</span>
</div>

3. chat with append plus replay

Disconnect-resilient feed. Cursor in sessionStorage, server replays missed messages on reconnect.

<ul _herald="/sse" _herald-subscribe="chat:lobby" id="feed"></ul>

<!-- server publishes append fragments -->
<hh-fragment channel="chat:lobby" target="#feed" swap="append">
  <li><b>alice</b>: hi</li>
</hh-fragment>

4. LLM token streaming

Progressive text. Suspense slot accepts hh-partial chunks until final.

<article _herald="/sse"
         _herald-subscribe="reply:99"
         _herald-suspense="reply-99">
  <p id="answer">thinking...</p>
</article>

<!-- each token -->
<hh-partial channel="reply:99" target="#answer" suspense_id="reply-99">
  the wire
</hh-partial>

5. status feed (htmx plus hyperherald)

Pushed HTML carries hx-* attrs. htmx upgrades them via MutationObserver. Cascades just work.

<hh-fragment channel="orders:42" target="#row-42" swap="outer">
  <tr id="row-42" hx-get="/orders/42" hx-trigger="click" hx-target="#detail">
    <td>shipped</td><td>$240</td>
  </tr>
</hh-fragment>
