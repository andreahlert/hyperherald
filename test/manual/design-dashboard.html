Why this exists

htmx covers request/response. _hyperscript covers behaviour. Server push has been bolt-on. _hyperstream fills the gap: subscribe in HTML, replay on reconnect, fan-out one event to N targets, all without leaving hypermedia.

The wire format

Every push is a single self-describing custom element. No JSON envelope.

// example: a single fragment swap
<hs-fragment channel="auction:lot-1"
              seq="42"
              target="#price"
              swap="inner">
  <strong>$120</strong>
</hs-fragment>
