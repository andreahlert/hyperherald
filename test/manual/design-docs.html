_hyperstream

Declarative server-push hypermedia. HTML over the wire, all the way down. Five kilobytes brotli, zero dependencies.

$ npm install hyperstream.org

Why

htmx handles request/response. _hyperscript handles client behaviour. _hyperstream is the third primitive: server-push. Subscribe in HTML, replay on reconnect, fan out one push to many targets.

No JSON envelope. Frames are self-describing custom elements. The wire is hypermedia.

The wire format

Every push is a single custom element. The same shape covers fragment swaps, atomic batches, partial streams, subscribe acks.

// example: a single fragment swap
<hs-fragment channel="auction:lot-1"
              seq="42"
              target="#price"
              swap="inner">
  <strong>$120</strong>
</hs-fragment>
