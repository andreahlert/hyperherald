_hyperstream

a tiny protocol for streaming HTML fragments straight into the page. no JSON. no signals. just hypermedia, all the way.

P.S. — try it: npm i hyperstream.org

the wire

<hs-fragment channel="auction:lot-1"
              seq="42"
              target="#price"
              swap="inner">
  <strong>$120</strong>
</hs-fragment>

the page

current bid$120
leaderalice
time left00:30

HTML wire

frames are custom elements. read 'em as HTML. that's it.

fan-out

one push, many targets. like sending a postcard to a list.

replay

connection drops? cursor remembers. nothing is lost.

htmx friend

pushed HTML carries hx-* attrs. just works.
