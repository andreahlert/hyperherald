N° 01 · WIRE

HTML, all the way down

Frames are self-describing custom elements. No JSON envelope, no client-side parser, no translation layer. Hypermedia from server to DOM.

N° 02 · FAN-OUT

One push, every subscriber

Multi-element subscriptions on the same channel. One server event, N targets updated atomically across tabs.

N° 03 · REPLAY

Reconnect without gaps

Per-channel cursor in sessionStorage. SSE Last-Event-ID, WS hs-subscribe handshake. Continuity by default.

N° 04 · htmx

Composes, doesn't compete

Pushed HTML carries hx-* attributes. htmx upgrades them on swap via MutationObserver. No coordination required.
