_hyperstream

finally... server-push hypermedia.

Streaming HTML without tears: declarative subscribe, replay, atomic & multi swaps over SSE / WS. 5KB brotli, zero deps, install with a script tag.

auction.html
<!-- subscribe a fragment to a channel -->
<div _stream="/sse"
     _stream-subscribe="auction:lot-1">
  <span id="price">$100</span>
  <span id="leader">—</span>
  <span id="countdown">60</span>
</div>

<!-- server pushes pure HTML envelopes -->
<hs-atomic channel="auction:lot-1" seq="42">
  <hs-fragment target="#price" swap="inner">
    <strong>$120</strong>
  </hs-fragment>
</hs-atomic>

HTML Over The Wire

Frames are self-describing custom elements (<hs-fragment>, <hs-atomic>). No JSON envelope. Hypermedia from server to DOM, no translation layer.

Pub/Sub Native

Multiple elements subscribe to one channel; one frame fans out to N targets. Multi-tab atomic updates without OOB hacks.

Replay On Reconnect

Per-channel cursor in sessionStorage, resumed via Last-Event-ID on SSE or <hs-subscribe cursors> on WS. No gaps.

Composes With htmx

Pushed HTML can carry hx-* attrs; htmx upgrades them via MutationObserver. Same cascade as _hyperscript.
