HTML over the wire, all the way down. Subscribe, replay, atomic and multi swaps. Five kilobytes brotli, zero deps, plays nice with htmx.

HTML, all the way

Frames are self-describing custom elements. No JSON envelope. Hypermedia from server to DOM, no translation.

Native pub / sub

Many elements share one channel. One push fans out to N targets. Multi-tab atomic, no OOB hacks.

Replay on reconnect

Per-channel cursor in sessionStorage, resumed via Last-Event-ID on SSE or hs-subscribe on WS. No gaps.

Composes with htmx

Pushed HTML can carry hx-* attributes. htmx upgrades them via MutationObserver. Cascades just work.
